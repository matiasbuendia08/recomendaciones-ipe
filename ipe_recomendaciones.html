IPE · ARCHIVO DE RECOMENDACIONES

Extractor de recomendaciones de política pública

Organiza tus documentos del Instituto Peruano de Economía por tema. Cada bloque procesa sus propios archivos y separa solo las recomendaciones de política pública, citando el documento de origen.

Los archivos se leen aquí en tu navegador. El texto extraído se envía a la API de Claude (Anthropic) únicamente para identificar las recomendaciones — no se sube ni almacena en ningún servidor.
